# UI/UX 设计参考手册

> 2026-07-31 网络调研，为"自我画像"PWA 项目提供 UI 设计决策依据。

---

## 一、字体方案

### 中文正文：无衬线（屏幕阅读最优）

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Microsoft YaHei", "Source Han Sans SC",
             "Noto Sans CJK SC", sans-serif;
```

### 标题点缀：衬线（制造"个人档案"的质感）

```css
font-family: "Noto Serif CJK SC", "Source Han Serif SC",
             "Songti SC", "STSong", serif;
```

### 设计决策

- **正文 100% 无衬线**（移动端阅读舒适，参考知乎/石墨文档）
- **报告页标题用衬线**（制造"档案/文件"的正式感）
- **西文在前、中文在后**（西文数字更好看）
- 字体大小基准：正文 16px，问题标题 18px，报告标题 28px

## 二、配色方案

### 方案选定：深色主题 + 暖色点缀

参考人格测试 App 的主流趋势（Persona Atlas、PSYCH//OS），深色底能营造"内省/深度思考"的氛围，减少长时间作答的眼疲劳。

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景 | `#0f0f14` | 最深底色 |
| 卡片/输入区 | `#1a1a24` | 次要容器 |
| 卡片悬停 | `#222233` | hover 状态 |
| 主强调色 | `#c4a45a`（暖金） | 按钮、进度、选中态 |
| 次强调色 | `#7b68ee`（中紫） | 链接、图表装饰 |
| 正文 | `#e8e8ed` | 主文字 |
| 次要文字 | `#8a8a9a` | 辅助说明、提示 |
| 成功/积极 | `#4ecdc4`（青绿） | 完成、正向指标 |
| 边框 | `#2a2a38` | 分割线、输入框边框 |

### 为什么选暖金 + 深色？

- 暖金（`#c4a45a`）在深色背景上温暖但不刺眼，不像纯白或霓虹色那样有"科技感过强"的问题
- "自我认知"是温和内省的过程，不是冷冰冰的数据分析
- 紫色（`#7b68ee`）作为副色增加深度和维度感（报告中区分不同人格维度）

## 三、布局原则

### 瀑布流（用户选定的 B 方案）

- **单一长页面**，所有题目从上到下排列
- **6 大领域**以视觉分割（粘性小节标题）区分
- 每个题目作为独立卡片，卡片间距 16px
- 移动端单列，桌面端最大宽度 640px 居中

### 导航辅助（长页面必备）

| 组件 | 位置 | 功能 |
|------|------|------|
| 顶部进度条 | 固定顶部 | 已答/总计 + 百分比 |
| 领域导航 | 侧边悬浮（桌面）或底部抽屉（移动） | 快速跳转到任一领域 |
| 回到顶部按钮 | 右下角悬浮 | 滚过 3 屏后出现 |
| 粘性小节标题 | 每个领域起始 | "一、身份根基 · 已答 38/50" |

### 渐进式揭示

- 首屏只显示简介 + 开始按钮
- 点击"开始"后滚动进入题目
- 每个领域之间有"休息区"——一句名言或反思提示

## 四、题目 UI 组件设计

### 7 种题目类型的视觉处理

| 类型 | 组件样式 | 动效 |
|------|---------|------|
| ⭐ Likert 5 级 | 水平排列 5 个圆形按钮，选中后填充暖金色 + 轻微缩放 | 选中: 缩放 1.1 → 1.0，200ms spring |
| ⭐ Likert 7 级 | 同上，7 个圆点 | 同上 |
| 🔘 单选 | 纵向排列圆角卡片选项，选中左边框变暖金色 | 选中: 边框色渐变 200ms |
| ☑️ 多选 | 方形勾选 + 卡片，选中后右上角出现 ✓ | 勾选: 描边动画 150ms |
| 📊 排序 | 拖拽排序列表（移动端用长按触发） | 拖拽: 位移 150ms ease |
| 📝 短文本 | 下划线输入框，聚焦后下划线变暖金色 + 变粗 | 聚焦: 线宽 1→2px，200ms |
| 📄 长文本 | 卡片内 textarea，自动增高 | 聚焦: 边框变亮 |
| 🎚️ 滑杆 | 自定义 range 滑块，轨道暖金色渐变 | 拖动: 即时跟随 |

### 关键交互细节

- **自动保存指示器**：题目卡片右上角显示 `已保存 · 3秒前`，状态变化时文字微闪
- **跳过标记**：每道题可点 `稍后回答`，卡片变为半透明 + 右侧出现橙色标记
- **领域完成提示**：一个领域全部答完后，小节标题旁出现 `✓` 动画

## 五、动效规范

### 动画时长与缓动

| 类型 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 微交互 | 100-150ms | `ease-out` | 悬停、点击反馈 |
| 选中/切换 | 200ms | `cubic-bezier(0.34,1.56,0.64,1)` | 选项选中、Spring 感 |
| 入场 | 300-400ms | `ease-out` | 卡片从下方淡入（滚动到视口时） |
| 进度条 | 400ms | `ease-out` | 进度条填充动画 |
| 页面过渡 | 250ms | `ease-in-out` | 领域间切换 |

### 入场动画策略

- 使用 `IntersectionObserver`，卡片进入视口时 `translateY(20px) → 0` + `opacity 0→1`
- **每个卡片只播一次**（`data-animated` 标记）
- **尊重 `prefers-reduced-motion`**——检测到后全部禁用动画
- **滚动时不用 `scroll` 事件**——用 `IntersectionObserver`，性能好得多

### 受控克制原则

> "定义每个动效的角色后再添加。如果没有明确功能，就去掉。"

## 六、移动端优先

### 断点

| 断点 | 设备 |
|------|------|
| < 640px | 手机（单列，全宽） |
| 640-1024px | 平板（居中，最大 640px） |
| > 1024px | 桌面（居中 640px + 侧边导航） |

### 移动端特殊处理

- 所有可点击元素最小 44×44px（iOS 规范）
- Likert 选项间距足够防止误触
- 输入框聚焦时不缩放页面（`font-size: 16px` 阻止 iOS 缩放）
- 底部留足安全距离（`env(safe-area-inset-bottom)`）
- 虚拟滚动中保留当前聚焦的输入框不被回收

## 七、报告页面设计

### 布局

- 顶部：姓名 + 日期 + 导出按钮
- 6 个领域各有独立区块：
  - 雷达图（Canvas/SVG）
  - 得分解读文字
  - 关键标签
- 底部：原始答案附录（折叠默认）

### 图表风格

- 坐标轴 + 网格线用 `#2a2a38`
- 数据区域用暖金 `#c4a45a` 半透明填充
- 文字标签用 `#e8e8ed`
- 暗色主题图表配色：
  - 主色：暖金 `#c4a45a`
  - 色阶：`#c4a45a`, `#d4b86a`, `#a08060`, `#7b68ee`, `#4ecdc4`, `#e8734a`

## 八、无障碍（a11y）

- 所有题目使用 `<fieldset>` + `<legend>` 语义结构
- 隐藏的 radio input 使用 `opacity: 0` 而非 `display: none`（保留键盘可访问性）
- 标题层级：H1(页面标题) → H2(领域名) → H3(题目)
- 颜色对比度满足 WCAG AA 标准
- `aria-rowcount` / `aria-rowindex` 用于虚拟滚动列表

## 九、质感升级策略（Premium Feel）

> 调研结论：廉价感通常来自"纯色 + 无纹理 + 无层次 + 多色混乱"。以下策略针对性解决。

### 9.1 底色不纯黑

```
❌ background: #000000;     // 纯黑 → 廉价
✅ background: #08080c;     // 带微妙的蓝紫底调
```

暗色背景携带品牌色的温度（我们的暖金偏暖底），避免"死黑"。

### 9.2 栅格点阵纹理（Grid Dots）

在深色背景上叠加 `background-image` 的微妙点阵：

```css
body {
  background-color: #08080c;
  background-image: radial-gradient(circle, rgba(255,255,255,0.03) 1px, transparent 1px);
  background-size: 24px 24px;
}
```

效果：背景不再是"一潭死水"，有了微妙的纹理质感。极低透明度，不干扰阅读。

### 9.3 噪点纹理（Noise/Grain）

叠加 SVG 噪点滤镜或 CSS `backdrop-filter`，消除 CSS 渐变中的色带（banding），让渐变过渡更自然。

### 9.4 亮度层级（Luminance Hierarchy）

Linear/Vercel 的核心技法：**暗色 UI 不用阴影表达层级，用亮度。**

| Token | 色值 | 用途 |
|-------|------|------|
| 页底色 | `#08080c` | 最深 |
| 卡片色 | `#121218` | 浮起一层 |
| 悬浮色 | `#1a1a22` | 悬停态 |
| 叠加层 | `#22222e` | Modal/弹窗 |

每一层亮度提升约 5-8%，都带一致的暖底调。

### 9.5 边框的艺术

```
❌ border: 1px solid #333;         // 粗硬黑线 → 廉价
✅ border: 1px solid rgba(255,255,255,0.06);  // 半透明白 → 精致
```

- 统一 **1px 宽度**，绝不加粗
- 半透明白色 `rgba(255,255,255,0.06-0.10)` 而非灰色
- 聚焦态用品牌色辉光（`box-shadow` 而非 `border` 变色）

### 9.6 内阴影高光（Inner Highlight）

卡片顶部加一道极细的高光：

```css
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.04),    /* 顶部微光 */
  0 4px 24px rgba(0, 0, 0, 0.3);               /* 底部投影 */
```

这让卡片有了"被光照亮顶部边缘"的立体感，却不需要渐变背景。

### 9.7 渐变边框（Gradient Border）

选中/聚焦的卡片使用 `::before` 伪元素 + `mask` 技法：

```css
.card-active::before {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  padding: 1px;
  background: linear-gradient(135deg, #c4a45a, rgba(196,164,90,0.2));
  -webkit-mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0);
  mask-composite: exclude;
}
```

效果：卡片边框从暖金渐变到透明，精致而不炫目。

### 9.8 单色系统（One Accent Rule）

```
❌ 按钮一种色、图表一种色、标签一种色、进度条一种色
✅ 暖金作为唯一强调色，仅在 2-3 个关键时刻出现
```

- 暖金 `#c4a45a` → CTA 按钮、进度条填充、选中态
- 中紫 `#7b68ee` → 图表色阶中的第二个颜色（必须用才用）
- 剩下 95% 的 UI 依靠**白色透明度层级**表达

### 9.9 字号克制

```
❌ 8 种字号 → 没有规律
✅ 5 种字号 + 严格节奏：12 / 14 / 16 / 20 / 28
```

参考 Linear 的紧凑间距哲学——"密集但留白大方"，信息密度高但视觉不拥挤。

### 9.10 动效原则

- 过渡统一 `transition: all 200ms ease-out`
- 悬停 `scale(1.01)` 而非 `scale(1.05)` ——微妙才高级
- 不再单独写 `transition`，全项目统一缓动曲线
