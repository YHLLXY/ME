## 1. Big Five（大五人格 / OCEAN）

**来源：** Costa & McCrae, 1980s-
**学术地位：** 人格心理学"金标准"，跨文化效度极强

| 维度 | 英文 | 含义 | 高分的表现 | 低分的表现 |
|------|------|------|-----------|-----------|
| 开放性 | Openness | 对新经验的接纳程度 | 好奇、创意、抽象思维 | 务实、传统、偏常规 |
| 尽责性 | Conscientiousness | 自控力与组织性 | 自律、有条理、可靠 | 随性、灵活、不拘束 |
| 外倾性 | Extraversion | 社交能量取向 | 健谈、活跃、喜社交 | 内敛、独处充电 |
| 宜人性 | Agreeableness | 合作与共情倾向 | 信任、利他、配合 | 竞争、质疑、直率 |
| 情绪稳定性 | Neuroticism (反向) | 情绪波动程度 | 放松、抗压、情绪平稳 | 焦虑、敏感、易波动 |

**问卷引用：** 每个维度 8-12 题 Likert 5 级量表，共约 50 题（感知层核心量表）
**报告引用：** 五维雷达图 + 各维度文字解读

## 2. MBTI（迈尔斯-布里格斯类型指标）

**来源：** Myers & Briggs, 1940s（基于荣格理论）
**学术地位：** 广泛应用但信效度有限（重测信度仅 0.39-0.76）

| 轴 | 两端 | 含义 |
|----|------|------|
| E/I | 外向 / 内向 | 能量来源——人群 vs 独处 |
| S/N | 实感 / 直觉 | 信息接收——具体事实 vs 抽象模式 |
| T/F | 思考 / 情感 | 决策方式——逻辑 vs 价值观 |
| J/P | 判断 / 感知 | 生活态度——计划 vs 随性 |

**注意：** MBTI 更适合作为"自我认知的启发"而非精确诊断。建议在问卷中使用连续量表而非强制二分。
**问卷引用：** 4 个轴各 5-8 题 Likert 量表，约 25 题（感知层）
**报告引用：** 四个维度的百分比倾向 + 类型描述文字

## 3. Enneagram（九型人格）

**来源：** 古传统 + 现代心理学整合
**焦点：** 核心恐惧与欲望，比 MBTI/Big Five 更深入动机层面

| 类型 | 名称 | 核心恐惧 | 核心欲望 |
|------|------|---------|---------|
| 1 | 完美主义者 | 犯错/不道德 | 做好事、正直 |
| 2 | 助人者 | 不被爱 | 被需要、被爱 |
| 3 | 成就者 | 无价值 | 成功、被认可 |
| 4 | 个人主义者 | 平凡/缺乏意义 | 独特、真实 |
| 5 | 探索者 | 无知/被吞噬 | 理解、掌握 |
| 6 | 忠诚者 | 无安全感/被抛弃 | 安全、可靠 |
| 7 | 热爱者 | 被困/痛苦 | 快乐、满足 |
| 8 | 挑战者 | 脆弱/被控制 | 自我保护、掌控 |
| 9 | 和平者 | 冲突/分离 | 和谐、稳定 |

**问卷引用：** 每类型 3-4 题 Likert 量表，约 35 题（感知层 + 叙事层），寻找最契合的类型
**报告引用：** 主导类型 + 翼型 + 整合/解离方向

## 4. HEXACO 六因素模型

**来源：** Ashton & Lee, 2000s
**亮点：** 在 Big Five 基础上增加了"诚实-谦逊"维度

| 维度 | 含义 |
|------|------|
| 诚实-谦逊 (H) | 真诚公平 vs 操控自利 |
| 情绪性 (E) | ≈ Big Five Neuroticism |
| 外倾性 (X) | ≈ Big Five Extraversion |
| 宜人性 (A) | 宽恕温和 vs 易怒固执 |
| 尽责性 (C) | ≈ Big Five Conscientiousness |
| 经验开放性 (O) | ≈ Big Five Openness |

**问卷引用：** H 维度 5-8 题（感知层），其余可被 Big Five 覆盖
**报告引用：** H 维度单独呈现

## 5. 卡特尔 16PF

**来源：** Raymond Cattell, 1940s
**特点：** 16 个基本人格因子，粒度最细

16 个因子：乐群性(A)、聪慧性(B)、稳定性(C)、恃强性(E)、兴奋性(F)、有恒性(G)、敢为性(H)、敏感性(I)、怀疑性(L)、幻想性(M)、世故性(N)、忧虑性(O)、实验性(Q1)、独立性(Q2)、自律性(Q3)、紧张性(Q4)

**问卷引用：** 精选关键因子 8-10 个各 2-3 题（感知层补充）
**报告引用：** 仅在因子得分极端时提及

## 6. CliftonStrengths（盖洛普优势识别器）

**来源：** Gallup / Donald Clifton
**核心理念：** 发现并发展天赋，而非修补弱点

### 四大领域 34 项天赋

| 领域 | 9 项天赋 |
|------|---------|
| **执行力** | 成就、统筹、信仰、公平、审慎、纪律、专注、责任、排难 |
| **影响力** | 行动、统率、沟通、竞争、完美、自信、追求、取悦 |
| **关系建立** | 适应、关联、伯乐、体谅、和谐、包容、个别、积极、交往 |
| **战略思维** | 分析、回顾、前瞻、理念、搜集、思维、学习、战略 |

**问卷引用：** 34 项各 1-2 题强制选择 + Likert，约 50 题（感知层核心量表）
**报告引用：** Top 10 天赋 + 四大领域分布图

## 7. 情商模型（Goleman / MSCEIT）

**来源：** Daniel Goleman (1995) / Mayer, Salovey, Caruso (MSCEIT)

### Goleman 四领域模型

| | 自我 | 他人 |
|------|------|------|
| **认知** | 自我觉察 | 社会觉察（共情） |
| **调节** | 自我管理 | 关系管理 |

五个核心能力：自我觉察 → 自我调节 → 动机 → 共情 → 社交技能

**问卷引用：** 5 个维度各 3-5 题 Likert + 情景题，约 20 题（感知层）
**报告引用：** 五维雷达图

## 8. Schwartz 价值观理论

**来源：** Shalom Schwartz, 1992

### 19 种精炼价值观 → 10 种基本类型 → 4 个高阶维度

| 高阶维度 | 包含的基本价值观 |
|----------|----------------|
| **对变化的开放** | 自我导向(思想+行动)、刺激、享乐 |
| **自我增强** | 成就、权力(支配+资源)、面子 |
| **保守** | 安全(个人+社会)、传统、遵从(人际+规则)、谦逊 |
| **自我超越** | 普世主义(关心+自然+宽容)、仁爱(可靠+关怀) |

**核心理念：** 价值观形成环形连续体，相邻的兼容，相对的冲突
**问卷引用：** 使用 PVQ 风格"第三人口述"法（"这个人和你有多像？"），约 30 题（感知层核心量表）
**报告引用：** 价值观环形图 + 高阶维度得分

## 9. Ikigai 生存意义框架

**来源：** 日本传统文化概念

### 四个基础维度 + 四个交集

```
       你热爱的         你擅长的
           \            /
            \  激情    /
             \  /  \  /
              ✦ Ikigai ✦
             /  \  /  \
            /  使命 职业 \
           /            \
      世界需要的      你能获酬的
```

- **激情** = 热爱 + 擅长
- **使命** = 热爱 + 世界需要
- **职业** = 擅长 + 获酬
- **天职** = 世界需要 + 获酬

**问卷引用：** 4 个维度各 3-5 题开放式简答，约 15 题（叙事层核心）
**报告引用：** 四圆图文 + 交集分析

## 10. 田纳西自我概念量表（TSCS）

**来源：** Fitts, 1965（中文版：林邦杰, 1978）

### 3 个结构维度 × 5 个内容维度

| 结构\内容 | 生理 | 道德 | 心理 | 家庭 | 社会 |
|-----------|------|------|------|------|------|
| 自我认知 (我是谁) | ✓ | ✓ | ✓ | ✓ | ✓ |
| 自我满意 (我满意吗) | ✓ | ✓ | ✓ | ✓ | ✓ |
| 自我行动 (我怎么做) | ✓ | ✓ | ✓ | ✓ | ✓ |

**问卷引用：** 精选 30-40 题 Likert 量表（感知层补充）
**报告引用：** 自我认知 vs 自我满意的差距分析

## 方法论使用原则

1. **多框架交叉验证：** 同一概念用不同框架度量（如"外倾性"同时出现在 Big Five、MBTI、16PF），取交集增强可信度
2. **连续优于二分：** 所有类型学框架（MBTI、Enneagram）使用连续量表而非强制二分
3. **深度优于广度：** 简答题（叙事层）的价值不亚于量表题，它们提供量表分数背后的"为什么"
4. **文化适配：** 中国人本土大七与西方 Big Five 并存展示，提供文化视角的参照
5. **不自欺：** 参考 TSCS 的"自我批评"因子，在问卷中埋入一致性校验
